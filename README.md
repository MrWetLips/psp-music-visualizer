# RetroViz — PSP Music Visualizer

Ретро-визуализатор для PSP в стиле японских автомагнитол Alpine/Kenwood/Sony 90-х.

## Управление

| Кнопка | Действие |
|--------|----------|
| **L** | Предыдущий визуализатор |
| **R** | Следующий визуализатор |
| **▲** | Следующий трек |
| **✕** | Предыдущий трек |
| **HOME** | Выход |

## Режимы (8 штук)

1. **EQ Bars** — классические столбики EQ в стиле Alpine
2. **Oscilloscope** — осциллограф на тёмном фоне
3. **Circular Spectrum** — круговой спектр
4. **VU Meters** — два VU-метра L/R
5. **Dot Matrix** — матрица точек
6. **Starfield** — звёздное поле
7. **Sony MDX** — пиксельный дисплей Sony MDX-M870PE
8. **Kenwood VFD** — дисплей Kenwood DPX-440 SPEC режим

## Установка

1. Скачай `EBOOT.PBP` из раздела **Actions → Artifacts**
2. Создай папку `PSP/GAME/RetroViz/` на карте памяти
3. Скопируй `EBOOT.PBP` в эту папку
4. Запусти с XMB → Игры → Карта памяти

## Требования

- PSP с кастомной прошивкой (CFW) — например 6.61 Infinity + PRO/ME
- Карта памяти Memory Stick

## Сборка

Автоматически через GitHub Actions при каждом push в `main`.
